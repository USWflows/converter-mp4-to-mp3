        Keyboard shortcuts and device help

        Ctrl/⌘ + O choose media · Ctrl/⌘ + Enter convert · Esc stop recording. The microphone recorder requires secure browser permission. Save As uses your browser’s native save picker when supported. GIF and large 1080p exports can be slow; prefer 480p/720p on phones.

        How do I use Pulse Studio?

        Select a conversion type, add files, select a profile, then convert. Use Advanced tools to trim, clean and merge. Save or share each finished file. On iPhone, Share → Save to Files is often easiest. Keep the tab open while exporting.
